# TaoPat

A realtime "pat the character" web game. Chibi Hu Tao sits on a vermilion seal; click or tap her to pat, hear a sound, and watch the counter climb. A Socket.IO leaderboard tracks pats per region in real time.

## Getting started

```bash
npm install
npm start
```

Open <http://localhost:3000> in your browser.
